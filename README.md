# chamados-backend
Repositório back-end do projeto de chamados.

## Tecnologias utilizadas
- Java
- Spring
- Spring Data
- Docker e Docker Compose
- Swagger
- Banco de dados Postgres
- Banco em memória H2
- Gerenciador de dependências Maven
